# ausi-tools

Extensie Chrome/Brave (Manifest V3) care adaugă funcții de import/export Excel în AUSI (`transfer.rocnee.eu/ausi`).

## Instalare
1. `brave://extensions` (sau `chrome://extensions`) → activați **Developer mode**.
2. **Load unpacked** → selectați folderul extensiei.

## Utilizare
- **Export** – descarcă `export_ausi.xlsx` cu toate persoanele de contact.
- **Import** – încărcați un fișier `.xlsx` cu același format ca exportul. Bifați „Sincronizare SIIIR” pentru a actualiza și centrul de comunicare / codul SIIIR.
